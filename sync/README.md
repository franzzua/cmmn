# @cmmn/sync

Collaborative features and synchronization primitives using [loro-crdt](https://loro.dev/).

## Features

- **CRDT Storage**: Local-first storage with Conflict-free Replicated Data Types.
- **P2P Synchronization**: Peer-to-peer data syncing capabilities.
- **Transport Layer**: Abstractions for network transport.
- **RPC**: Remote Procedure Calls for distributed systems.

## Usage

This package provides the foundation for building collaborative applications. It includes modules for:

- `crdt`: Handling data consistency.
- `p2p`: Managing peer connections.
- `transport`: Defining how data moves between nodes.
